# Lumina Finishers | Architectural Painting & Fine Surface Coatings

A high-converting showcase portfolio website engineered for luxury residential painting contractors, cabinet refinishing specialists, and architectural finishing studios.

## Highlights & Features
- **Visual Aesthetic:** Refined slate and obsidian dark tones with warm linen textures, Playfair Display typography, and amber accents.
- **Interactive Swatch Studio & Visualizer:** Real-time architectural color palette selector (Benjamin Moore Hale Navy, Chantilly Lace, Farrow & Ball Bancha Olive, Kendall Charcoal) that simulates room backdrop tones, undertones, and finishes live on-screen.
- **Instant Project Cost & Timeline Calculator:** Dynamic interactive estimator adjusting by project category (Full Interior, Cabinet Spray Lacquering, Exterior Facade), square footage slider (600 to 6,500+ sq ft), and formulation grade (BM Aura vs. Farrow & Ball Estate).
- **The Zero-Dust Standard Comparison Table:** Side-by-side contrast of standard painter pitfalls versus clinical 5-Stage Zero-Dust HEPA containment.
- **Conversion Architecture:**
  - Certified partner trust badges (Benjamin Moore, Farrow & Ball, Fine Paints of Europe, Sherwin-Williams Emerald).
  - Bento grid highlighting cabinet lacquering (saving 70% vs replacement), Level 5 skim coating, and Venetian plaster.
  - Case studies with quantified client savings and specifications.
  - Interactive FAQ accordion addressing odor/VOCs, cabinet durability, and furniture protection.
  - Modal lead capture form with instant appointment confirmation.
- **Tech Stack:**
  - HTML5 & Semantic Elements
  - Tailwind CSS via CDN
  - Lucide Icons
  - Google Fonts (Playfair Display & Outfit)
  - 100% Mobile Responsive with zero build-step dependencies

## Setup & Deployment
Open `index.html` directly in any web browser or deploy immediately to GitHub Pages, Netlify, or Vercel:

```bash
# Push to GitHub
git remote add origin https://github.com/YOUR_USERNAME/lumina-finish-painters.git
git branch -M main
git push -u origin main
```
